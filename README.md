A token launch radar: a Node.js program that reads a sealed DeFiLlama snapshot of 758 protocols, ranks 200 by a comps-based implied value (TVL × category multiple × growth × age × chain × launch prior), and serves a sortable, filterable dashboard with per-protocol farm plans. Board: 123 pre-token / 72 trading / 5 anomaly; all 40 watchlist protocols covered. Built by an AI agent for make.fun's token-radar-01 bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
